Montreal Forced Alignment (MFA) Workflow

Step-by-step instructions to set up Montreal Forced Aligner with the standard english_us_arpa acoustic model and pronunciation dictionary:

1. Conda Environment Setup

# Create isolated environment for MFA
conda create -n mfa -c conda-forge montreal-forced-aligner kaldi -y
conda activate mfa

2. Model & Dictionary Provisioning

# Download pre-trained acoustic model and dictionary
mfa model download acoustic english_us_arpa
mfa model download dictionary english_us_arpa

3. Corpus Alignment

# Align corpus to produce Praat TextGrid interval tiers
mfa align data/raw lexicons/sample_lexicon.txt english_us_arpa outputs/textgrids --clean --num_jobs 4

4. Or Use Our Bundled Script

# Automated wrapper script in this repository
bash scripts/setup_mfa.sh check
bash scripts/setup_mfa.sh install
bash scripts/setup_mfa.sh download
bash scripts/setup_mfa.sh align data/raw lexicons/sample_lexicon.txt outputs/textgrids

Command-Line Interface & Docker Execution

Run the evaluation tool directly via standard Python CLI or containerized Docker:

Standard Python CLI

# Table output with word, char, and match error rates
context-demo --manifest examples/toy_manifest.jsonl --format table

# Full evaluation with ARPAbet lexicon and Phone Error Rate (PER)
context-demo --manifest examples/toy_manifest.jsonl --lexicon lexicons/sample_lexicon.txt --format table

# Machine-readable structured JSON output
context-demo --manifest examples/toy_manifest.jsonl --lexicon lexicons/sample_lexicon.txt --format json

Docker Container Run

# Build locally
docker build -t did-the-word-survive:latest .

# Run default table evaluation
docker run --rm did-the-word-survive:latest

# Run with lexicon in Docker
docker run --rm did-the-word-survive:latest --lexicon lexicons/sample_lexicon.txt --format table
